# Agentic Security Evaluation

Shared evaluation framework for the three implementations
of the agentic security prototype.

## Implementations

- V1: Insecure baseline
- V2: Application-level manual security enforcement
- V3: System-level policy enforcement

## Evaluation Areas

- Security effectiveness
- Legitimate functionality
- Agent behavior
- Performance
- Developer effort and complexity
- Reusability

## Structure

- adapters/: Integration with the three implementations
- config/: Evaluation configuration
- fixtures/: Shared test data
- scenarios/: Evaluation scenarios
- experiments/: Experiment execution
- scoring/: Metrics and scoring
- analysis/: Comparative analysis
- tests/: Framework tests
- results/: Generated evaluation outputs
